# Edwards Precision Mobile — Public Demo (21-11-2026)

This is a **public, fictional-data-only** preview for GitHub Pages. The Office/Factory switch previews screens only; it is **not** authentication or authorisation. Job editing, employee logins, Smartsheet, Microsoft 365, QuickBooks, NCR submissions and SDNR issuance are **not connected**. Do not upload customer data, passwords, credentials or tokens here.

## Replace the existing staging demonstration on GitHub

1. Open `https://github.com/julie903/edwards-precision-mobile-demo`.
2. Use **Add file > Upload files**.
3. Upload **all files inside this extracted folder**, not the ZIP and not the outer folder. They must be at the repository root beside `README.md`.
4. Where prompted, choose to replace existing files with the same name, then **Commit changes**.
5. Ensure `index.html`, `app.js`, `styles.css`, `manifest.webmanifest` and the icons are all visible at the root.
6. Once deployment completes, open `https://julie903.github.io/edwards-precision-mobile-demo/` in Safari. The public demo should show dashboard figures and role previews, not 'No verified session'.

## Add to an iPhone's Home Screen

Open the URL in **Safari on the iPhone**, choose **Share > Add to Home Screen > Add**. This adds the demo app icon, but **does not provide protected access to company systems**.

## Safety and hosting

GitHub Pages is **public**. There is no real employee authentication in this demo. No live data is included. This demonstration has no service worker/offline cache. Secure Microsoft Entra sign-in and backend role checks must be implemented on separate suitable protected hosting before using company data.
